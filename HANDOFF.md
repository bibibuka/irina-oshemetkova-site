Корень сайта: `$env:USERPROFILE\Desktop\Сайт психолога` на Windows, PowerShell. Текущий чат может оставаться привязанным к старому workspace бота; команды сайта запускать с явным рабочим каталогом новой папки.

Полный перечень возможностей, происхождение материалов, команда запуска и правила публикации уже описаны в **`README.md`** — прочитать его, не восстанавливать проект с нуля.

PID не фиксируется в документации: проверять доступность URL и владельца порта перед любым запуском. Сервер: `server.py`. Порядок запуска и смены порта — в README. Он обслуживает только `dist` на loopback. Не запускать второй экземпляр на занятом порту. Пользователь просил оставить localhost работающим.

Никакой регистрации Sites, публичного деплоя, оплаты, отправки сообщений или изменения самого бота не выполнялось.

## Карта файлов и важные зависимости

| Файл | Назначение |
| --- | --- |
| `dist/index.html` | Все секции, локальные изображения, разметка девяти диалогов, подключения файлов |
| `dist/styles.css` | Основной дизайн и адаптивная вёрстка; индивидуальное кадрирование фотографий |
| `dist/features.css` | Блок трёх новых инструментов, их диалоги и плавающая панель быстрых действий |
| `dist/readability.css` | Крупный текст, контраст, новые адаптивные сетки и размеры элементов управления |
| `dist/app.js` | Первоначальные интерактивы и общая инфраструктура диалогов |
| `dist/features.js` | Трёхшаговый подбор поддержки, заземление, конструктор просьбы, режим крупного текста |
| `dist/assets/` | Настоящие фотографии и документы со старого сайта, локальные шрифты, лицензии |

**Порядок CSS важен:** `styles.css` → `features.css` → `readability.css`. Последний файл намеренно перекрывает мелкие размеры из исходного дизайна. Нельзя считать изменение старого правила в `styles.css` достаточным, не проверив каскад.

**Порядок JS:** `app.js` → `features.js`, оба `defer`. Диалоги находятся в исходном HTML до исполнения скриптов. `app.js` подписывает все существующие диалоги на закрытие/Escape/backdrop; `features.js` закрывает предыдущее окно перед переходом к другому, чтобы не накладывать модальные окна. Класс `html.dialog-open` управляет блокировкой прокрутки.

Приложение без сборки, npm и фреймворка. Не мигрировать стек без необходимости.

## Обратная связь пользователя, которую важно сохранить

- Пользователь хочет выразительный современный сайт и **реально работающие, заметные функции**. Последняя версия вынесла три новых инструмента сразу после первого экрана; главная кнопка «Найти свою опору» теперь открывает подбор поддержки, а не запись.
- Главная претензия к предыдущей версии — очень мелкий текст. Сейчас основной текст 17 px, вводный 18–20 px, кнопки около 16 px. «Aa» увеличивает основной текст до 19 px. Не возвращаться к содержательному тексту 10–12 px ради свободного пространства.
- Пользователь отдельно заметил обрезанную голову ребёнка на фотографии. Карточки теперь имеют стабильные пропорции и индивидуальные точки кадрирования; не возвращать фиксированную высоту широких карточек.
- Дизайн: молочный фон, шалфейный зелёный, терракотовые акценты, Cormorant Garamond + Inter, арочный настоящий портрет, спокойная анимация с reduced-motion.

### Кадрирование, которое уже исправляли

Основные правила в `styles.css`: `.resource-image` имеет `aspect-ratio:3/2`, на узких экранах — `4/3`, `height:auto`. Классы `resource-image--child`, `--family`, `--baby` задают переменную `--photo-position`; она применяется также к `transform-origin` при наведении.

Точки: ребёнок на закате — `50% 42%`, семья на пляже — `50% 50%`, крупный план малыша — `50% 0%`. Макушка на последнем изображении обрезана уже в оригинале: CSS сохраняет глаза, лицо и подбородок. Портрет специалиста — `50% 40%`; тюльпаны на узком экране — `50% 75%`. `readability.css` дополнительно меняет сетки и положение цитаты поверх тюльпанов: при будущих изменениях проверять не только object-position, но и перекрытие изображений текстом.

Мобильные переносы в заголовках карточек скрываются CSS; вокруг `<br>` оставлены пробелы, чтобы слова не склеивались.
