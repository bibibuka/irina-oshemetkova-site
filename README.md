# Сайт Ирины Ошемётковой — «Свет в окне»

Сайт перинатального психолога Ирины Ошемётковой. Это статичный HTML, CSS и JavaScript: сборка, npm и подключение к боту не нужны. Шрифты и фото лежат локально, внешних запросов при загрузке страницы нет. Ход работы и решения описаны в `HANDOFF_REDESIGN.md`. Старая версия сайта осталась в истории git (коммит `052a3e1`), её описывает `HANDOFF.md`.

## Запуск

Из корня репозитория:

```powershell
python server.py
```

Сайт откроется на http://localhost:3000. Другой порт: `python server.py --port 3001`. Если сервер уже запущен, второй раз его запускать не нужно.

Папка проекта: `$env:USERPROFILE\Desktop\Сайт психолога`. Терминал нужно открыть в этой папке.

Сервер отдаёт только папку `dist` и слушает `127.0.0.1`. К файлам бота, его базе и секретам доступа у него нет, список файлов в папках он не показывает.

**Режимы для просмотра.** Время суток, этап и тему можно подставить в адрес, не меняя часы: `?tod=morning|day|evening|night`, `?stage=planning|pregnancy|postpartum|loss|close|none`, `?theme=day|night`. Например, http://localhost:3000/?tod=night&stage=postpartum покажет тексты, которые увидит мама с малышом в три часа ночи. Сайт всегда открывается в светлой версии; тёмная включается только кнопкой-луной в шапке или в «Как мне удобнее».

## Что есть на странице

Каждый блок — **разворот книги**: левая и правая страница вокруг корешка, тихие колонтитулы сверху, колонцифры в нижних углах. У каждого разворота свой свет: из окна падают «стёкла» света на одну страницу, другая в мягкой тени, и от разворота к развороту меняются сторона и тон (утро — молоко, персик, шалфей, лён, закат, ночная лампа на зелёном). Разворот в середине экрана «зажигается», предыдущий гаснет. На телефоне страницы идут одна под другой, корешок превращается в линию с цветком. Заголовки — без точек в конце. Стили — `css/spreads.css`, поведение — `initSpreads()` в `js/core/motion.js`.

- **Шапка.** Имя, разделы «С чем помогаю · Об Ирине · Стоимость · Практики», луна «день/ночь», «Помощь» и «Записаться». На телефоне снизу док: «Помогаю · Практики · Цена · Запись · Помощь».
- **Окно (титульный разворот).** Заголовок «Быть мамой / Быть собой», кто Ирина и с чем помогает, кнопки «Записаться на консультацию» и «Попробовать практики», условия (50 минут · 4 000 ₽ · онлайн или очно в Петербурге), три факта доверия, арочный портрет на правой странице, приветствие по времени суток — в колонтитуле. Ниже закладкой — вопрос «Что сейчас про тебя?»: этап меняет заголовок, тексты и порядок вкладок практик; «Пережила потерю» открывает бережный порог и тихий режим.
- **«Может быть, ты узнаешь себя».** Слева ответ и переход к записи, справа восемь собирательных мыслей голосом клиенток; под разворотом — три нормализующие мысли.
- **«С чем я помогаю»** — разворот-оглавление: слева пять дверей-глав, справа открытая глава; при выборе главы разворот меняет свет (`data-chapter`). Утраты названы прямо, отдельно — для партнёров. «Записаться с этой темой» подставляет тему в письмо. Под оглавлением — форматы.
- **Ирина.** Слева портрет у окна, справа текст, где работала и чему училась, документы в лайтбоксе, кнопка записи.
- **Как я работаю** (`#podhod`). «Как я говорю — и как не говорю»: чего здесь не будет и шесть карточек-правил; под разворотом — «Что может стать иначе» (без обещаний) и «Честно о границах».
- **Стоимость и первая встреча.** Слева 4 000 ₽ / 50 минут и встреча вдвоём (стоимость при записи), справа четыре шага первой встречи, подготовка к онлайн-встрече и «напиши пару строк — скажу, моя ли это тема».
- **Практики — один блок с вкладками.** Открывается ночным разворотом с картой «Тело / Мысли / Связи», ссылки которой открывают нужные вкладки. Вкладки: «Как ты сейчас?» (чек-ин с подбором практики), «Подышать» (живой круг), «Полка практик» (5-4-3-2-1, «Контакт с чувствами», «Отложить мысли до утра», «Если накрывает воспоминание», «Экстренная остановка», «Выбери за меня»), «Разобрать мысль» (КПТ и 12 ловушек), «Слова близким» (фразы и конструктор просьбы), «Колода опор» (73 фразы). Под вкладками — разворот бота @PerinatMama_bot и закладка-переход к записи. Любая ссылка или кнопка, ведущая к практике, сама открывает её вкладку (`js/core/panels.js`, вызывается из `jumpTo`). Без JavaScript все практики идут подряд.
- **Вопросы** — в том числе «а если я буду плакать», конфиденциальность и её граница, почему нет отзывов, партнёр не хочет идти, что делать, пока ждёшь ответа, диагнозы, оплата и «если плохо ночью».
- **Письмо Ирине** собирается на «вы» по ходу заполнения. Отправляет его сама посетительница: текст копируется перед открытием Telegram, SMS и почта открываются с готовым текстом. Рядом прямые контакты и запасной путь через почту.
- **Помощь сейчас.** Лист с номерами 112, 103 и 8-800-2000-122 открывается из шапки, дока, подвала и тяжёлых ответов. В подвале те же номера работают и без JavaScript.
- **Как мне удобнее.** Этап, тема, крупный текст, меньше движения, звук, вибрация, «не предлагать дыхание», память и «Стереть всё».

## Приватность

По умолчанию сайт ничего не сохраняет и ничего не отправляет: нет cookies, аналитики и сетевых запросов. Память (`localStorage`, ключи `io.v1.*`) включается только переключателем «Запоминать на этом устройстве» и стирается одной кнопкой. Офлайн-копия ночника создаётся только по нажатию ссылки в «Ночнике», и «Стереть всё» её тоже удаляет. Наружу данные уходят только действием самой посетительницы: Telegram, SMS, почта, «Поделиться» или копирование.

## Структура

```
dist/
  index.html              вся разметка, SVG-спрайт, скрипт темы до первой отрисовки
  css/tokens.css          палитра дня и ночи, шрифты, шкалы
  css/base.css            сброс, типографика, кнопки, чипы, поля
  css/layout.css          шапка, док, полосы, подвал, свет из окна
  css/components.css      шторки, переключатели, подсказка о помощи, празднование
  css/motion.css          появления, бейдж
  css/spreads.css         развороты: страницы, корешок, колонтитулы, колонцифры, свет каждого разворота
  css/features/*.css      стили каждой секции; sales.css — первый экран, «узнаёшь себя», цена, блок практик
  js/main.js              запуск ядра и фич (каждая — отдельный import в try/catch)
  js/core/*.js            общие модули: dom, store, prefs, sheets, actions, panels (вкладки практик), share, audio…
  js/features/*.js        фичи; общаются только через data-action
  js/content/*.js         тексты (пулы бота, практики, ловушки, опоры, письмо)
  sw.js                   только снимает старый офлайн-кэш «Ночника» у тех, кто его ставил
qa/                       функциональные проверки Playwright без скриншотов
docs/research/            контент бота и концепции, из которых собран сайт
```

## Проверки

Нужен Python с Playwright (`pip install playwright` и один раз `playwright install chromium`). Сервер должен быть запущен:

```powershell
python qa/test_features.py       # 26 сценариев: воронка, вкладки практик, все фичи + «ничего не сохраняется без памяти»
python qa/test_interactions.py   # 17 проверок: вёрстка 320–1440 px, клавиатура, «Назад», док, анимации, без JS, сервер
```

Тесты блокируют все запросы за пределы localhost. Отчёты складываются в `qa/*-report.json`, в git они не попадают.

## Источники и редактура

Имя, специализация, фото, образование, контакты, длительность встречи 50 минут и цена 4 000 ₽ взяты с https://perinatmama.ru/. Рядом с ценой указано, что стоимость уточняется при записи. Тексты практик, фразы, ловушки мышления и опоры адаптированы из материалов бота Ирины (`docs/research/bot-content/`) по правилам бережности бота: не пугать, не винить, сначала чувство, без баллов и диагнозов. Медицинские утверждения из статей базы знаний на сайт не перенесены. Содержимое `.env`, базы данных и диалоги пользователей не использовались.

Шрифты: Cormorant Garamond и Inter, лицензии лежат в `dist/assets/`. Фото и сканы документов взяты с прежнего сайта психолога.

## Публикация

Сайт опубликован на GitHub Pages: https://bibibuka.github.io/irina-oshemetkova-site/. Pages отдаёт ветку `gh-pages`, в ней лежит только содержимое `dist/`. Workflow `.github/workflows/pages.yml` сам перекладывает `dist/` в `gh-pages` после каждого пуша в `main` или в рабочую ветку, если в `dist/` что-то изменилось. Его можно запустить и вручную на вкладке Actions. Обновление появляется на сайте через минуту-две.

Для любого другого статического хостинга достаточно папки `dist`.
