# Сайт Ирины Ошемётковой

Готовый самостоятельный сайт: HTML, CSS, JavaScript. Не требует сборки, npm или подключения к боту. Шрифты и фотографии находятся локально.

## Запуск

Из корня репозитория сайта:

```powershell
python server.py
```

Открыть http://localhost:3000. Для другого порта: `python server.py --port 3001`.

Если сайт находится в подпапке исходного проекта бота, сначала перейдите в неё: `cd website`.

Сервер обслуживает только `dist`, слушает `127.0.0.1` и не даёт доступа к файлам бота, его базе или секретам. Уже запущенный процесс не нужно запускать второй раз.

## Возможности

- Подбор первого шага по трём вопросам: этап, потребность и доступное время. Результат предлагает подходящую практику или разговор и передаёт выбранную тему в форму записи.
- Пошаговая практика 5–4–3–2–1 с возвратом, пропуском и повтором.
- Конструктор просьбы о поддержке: три примера, редактирование своими словами, живой результат и копирование текста.
- Крупная типографика 17–20 px и дополнительный режим «Aa»; настройка действует только в текущей вкладке.
- Четыре направления поддержки с переключением вкладок и клавиатурным управлением.
- Дыхательная практика на одну минуту с паузой, сбросом и завершением.
- Три материала с практическими шагами, эмоциональный check-in.
- Галерея реальных документов об образовании с увеличением.
- Подготовка и копирование сообщения для записи через публичный Telegram Ирины. Сообщение отправляет посетитель; форма сама не создаёт запись и не отправляет данные.
- Мобильное меню, FAQ, адаптивная вёрстка, reduced-motion, управление диалогами с клавиатуры.

## Источники и редактура

Имя, специализация, фото, образование, контакты, длительность 50 минут и опубликованная цена 4000 рублей взяты с https://perinatmama.ru/ и https://perinatmama.ru/education. Цена сопровождается указанием об уточнении при записи. Опыт в клиниках указан как опыт, без выдуманных лет стажа, отзывов и результатов.

Направления и идеи практик адаптированы из `bot/knowledge_constants.py`, `bot/handlers/practices.py`, `materials_data.json`. Непроверенные медицинские причинные утверждения из материалов не перенесены. Содержимое .env, БД и пользовательских диалогов не использовалось.

Шрифты: Cormorant Garamond (Google Fonts), Inter (локальные файлы проекта). Фотографии и сертификаты — с прежнего сайта психолога.

Для размещения на обычном статическом хостинге достаточно содержимого `dist`. Внешних сетевых зависимостей при загрузке страницы нет.
