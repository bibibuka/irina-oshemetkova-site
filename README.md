# Сайт Ирины Ошемётковой — «Свет в окне»

Сайт перинатального психолога Ирины Ошемётковой. Это статичный HTML, CSS и JavaScript: сборка, npm и подключение к боту не нужны. Шрифты и фото лежат локально, внешних запросов при загрузке страницы нет. Ход работы и решения описаны в `HANDOFF_REDESIGN.md`. Старая версия сайта осталась в истории git (коммит `052a3e1`), её описывает `HANDOFF.md`.

## Запуск

Из корня репозитория:

```powershell
python server.py
```

Сайт откроется на http://localhost:3000. Другой порт: `python server.py --port 3001`. Если сервер уже запущен, второй раз его запускать не нужно.

Папка проекта: `$env:USERPROFILE\Desktop\Сайт психолога`. Терминал нужно открыть в этой папке.

Сервер отдаёт только папку `dist` и слушает `127.0.0.1`. К файлам бота, его базе и секретам доступа у него нет, список файлов в папках он не показывает.

**Режимы для просмотра.** Время суток, этап и тему можно подставить в адрес, не меняя часы: `?tod=morning|day|evening|night`, `?stage=planning|pregnancy|postpartum|loss|close|none`, `?theme=auto|day|night`. Например, http://localhost:3000/?tod=night&stage=postpartum покажет страницу так, как её увидит мама с малышом в три часа ночи.

## Что есть на странице

- **Окно.** Приветствие подбирается по времени суток из фраз бота. Посетительница отвечает на вопрос «Что сейчас про тебя?», и от этапа зависят заголовок, порядок средних секций и тексты по всей странице. При выборе «Пережила потерю» сначала открывается бережный порог и включается тихий режим.
- **«Как ты сейчас?»** Пять состояний без цветовой оценки. В ответ приходит одна фраза и до трёх следующих шагов. При «очень тяжело» сначала показываются номера помощи и мини-круг дыхания.
- **Двери**: с чем приходят к Ирине. Кнопка «Написать об этом» сразу подставляет тему в письмо.
- **«Подыши со мной».** Живой круг по спецификации бота с четырьмя ритмами и тремя длительностями. Звук, вибрация, «закрой глаза» и приглушённый экран можно включить, по умолчанию они выключены. При reduced motion вместо анимации идёт текстовый таймер.
- **Полка практик.** Каждая практика открывается полноэкранной «комнатой»: 5-4-3-2-1, «Контакт с чувствами» (её итог можно сохранить картинкой), «Отложить мысли до утра», «Если накрывает воспоминание» (только для этапа потери), «Экстренная остановка» и «Выбери за меня».
- **Разбор мысли.** Четыре шага КПТ. Ловушки мышления подчёркиваются прямо при вводе. Силу чувства показывает сосуд со словами вместо цифр, а при «невыносимо» упражнение останавливается. Ниже — 12 карточек-ловушек и игра «Найди ловушку».
- **«Что сказать, когда…»** Фразы для партнёра, родных, советчиков, работы и для близких после утраты. Каждую можно скопировать, отправить или переделать под себя. Ещё здесь есть меню для гостей, памятка «Как мне помочь» и конструктор просьбы.
- **Колода опор.** 73 фразы бота. Карту можно вытянуть, оставить себе (только с включённой памятью) или сохранить как открытку и картинку на экран блокировки, без имени.
- **Ирина.** Фото, принципы «как я говорю — и как не говорю» на карточках, которые переворачиваются, и документы об образовании в лайтбоксе.
- **Ночник.** С 22:00 до 6:00 он становится первым экраном «Ночная смена»: человеческие часы («Начало четвёртого»), четыре крупные плитки и шум для сна. Шум генерируется в браузере и играет при заблокированном экране. По ссылке «Ночник на экран „Домой“» сайт можно сохранить для работы без интернета.
- **Карманная версия.** Демо бота @PerinatMama_bot с честной строкой о том, что в боте отвечает ИИ-ассистент.
- **Письмо Ирине** собирается на «вы» по ходу заполнения. Отправляет его сама посетительница: текст копируется перед открытием Telegram, а SMS и почта открываются с готовым текстом. Сайт ничего не отправляет.
- **Помощь сейчас.** Лист с номерами 112, 103 и 8-800-2000-122 открывается из шапки, дока, подвала и тяжёлых ответов. В подвале те же номера работают и без JavaScript.
- **Как мне удобнее.** Ночник, крупный текст, меньше движения, звук, вибрация, «не предлагать дыхание», память и список «Что знает этот сайт» с кнопкой «Стереть всё».

## Приватность

По умолчанию сайт ничего не сохраняет и ничего не отправляет: нет cookies, аналитики и сетевых запросов. Память (`localStorage`, ключи `io.v1.*`) включается только переключателем «Запоминать на этом устройстве» и стирается одной кнопкой. Офлайн-копия ночника создаётся только по нажатию ссылки в «Ночнике», и «Стереть всё» её тоже удаляет. Наружу данные уходят только действием самой посетительницы: Telegram, SMS, почта, «Поделиться» или копирование.

## Структура

```
dist/
  index.html              вся разметка, SVG-спрайт, скрипт темы до первой отрисовки
  css/tokens.css          палитра дня и ночи, шрифты, шкалы
  css/base.css            сброс, типографика, кнопки, чипы, поля
  css/layout.css          шапка, док, полосы, подвал, свет из окна
  css/components.css      шторки, переключатели, подсказка о помощи, празднование
  css/motion.css          появления, бейдж, дыхание света
  css/features/*.css      стили каждой секции
  js/main.js              запуск ядра и фич (каждая — отдельный import в try/catch)
  js/core/*.js            общие модули: dom, store, prefs, sheets, actions, share, audio…
  js/features/*.js        фичи; общаются только через data-action
  js/content/*.js         тексты (пулы бота, практики, ловушки, опоры, письмо)
  sw.js, manifest.webmanifest   «Ночник на экран Домой»
qa/                       функциональные проверки Playwright без скриншотов
docs/research/            контент бота и концепции, из которых собран сайт
```

## Проверки

Нужен Python с Playwright (`pip install playwright` и один раз `playwright install chromium`). Сервер должен быть запущен:

```powershell
python qa/test_features.py       # 24 сценария всех фич + «ничего не сохраняется без памяти»
python qa/test_interactions.py   # 14 проверок: вёрстка 320–1440 px, клавиатура, «Назад», док, без JS, сервер
```

Тесты блокируют все запросы за пределы localhost. Отчёты складываются в `qa/*-report.json`, в git они не попадают.

## Источники и редактура

Имя, специализация, фото, образование, контакты, длительность встречи 50 минут и цена 4 000 ₽ взяты с https://perinatmama.ru/. Рядом с ценой указано, что стоимость уточняется при записи. Тексты практик, фразы, ловушки мышления и опоры адаптированы из материалов бота Ирины (`docs/research/bot-content/`) по правилам бережности бота: не пугать, не винить, сначала чувство, без баллов и диагнозов. Медицинские утверждения из статей базы знаний на сайт не перенесены. Содержимое `.env`, базы данных и диалоги пользователей не использовались.

Шрифты: Cormorant Garamond и Inter, лицензии лежат в `dist/assets/`. Фото и сканы документов взяты с прежнего сайта психолога.

Для размещения на обычном статическом хостинге достаточно папки `dist`. Офлайн-режим ночника работает только по HTTPS.
