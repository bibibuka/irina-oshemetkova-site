# Сайт Ирины Ошемётковой — perinatmama.ru

Одностраничный сайт перинатального психолога. Статика: HTML, CSS, ванильный JS (ES-модули). Без сборки, npm, внешних шрифтов, аналитики и сетевых запросов. Всё для публикации — в папке `dist`.

## Запуск

```bash
python server.py            # http://localhost:3000
python server.py --port 3001
```

Сервер отдаёт только `dist` и слушает `127.0.0.1`.

Превью состояний через адресную строку: `?theme=night` (ночная тема), `?tod=morning|day|evening|night` (время суток для приветствия).

## Структура страницы (воронка)

1. **Первый экран** — оффер («Быть мамой. Быть собой.» + кто я и с чем помогаю), главная кнопка «Записаться на консультацию», вторая — «Практики без регистрации», условия (50 минут · 4 000 ₽ · онлайн/Петербург), три факта доверия, арочный портрет.
2. **«Возможно, вы узнаете себя»** — 8 мыслей клиенток по этапам и мягкий переход к записи.
3. **«С чем я помогаю»** — вкладки по этапам: планирование и ЭКО, беременность, после родов, утрата, пары и близкие. В каждой — «что бывает внутри», «над чем работаем» и кнопка «Записаться с этой темой» (тема сразу попадает в письмо).
4. **Обо мне** — текст, опыт («Медика», роддом им. Снегирёва), 6 принципов работы, документы об образовании с увеличением.
5. **Стоимость и формат** — индивидуальная консультация 4 000 ₽ / 50 минут, встреча для пары (стоимость при записи), 4 шага первой встречи.
6. **Практики — один блок.** Фильтр «Что сейчас громче?» (тревога, мысли по кругу, нет сил, не спится, нужны слова, очень тяжело), «Выберите за меня», 12 карточек, бот @PerinatMama_bot и карточка-переход к записи. Каждая практика открывается в полноэкранной «комнате» и заканчивается мягким предложением записаться.
7. **Вопросы** — 8 вопросов, включая конфиденциальность, диагнозы и «если плохо ночью».
8. **Запись** — конструктор письма Ирине (имя, формат, темы, удобное время, часовой пояс) с живым превью → «Скопировать и открыть Telegram», SMS, почта, звонок; контакты; «свободные окошки — в боте».
9. **Подвал** — финальный призыв, контакты, номера помощи.

На телефоне снизу появляется панель «Практики · Записаться · Помощь» (после первого экрана, скрывается над формой записи). В шапке — «Помощь сейчас» (шторка с номерами и шагами) и переключатель ночной темы (ночью включается сама).

## Практики

| Практика | Файл | Что внутри |
| --- | --- | --- |
| Подышать со мной | `js/practices/breath.js` | живой круг, ритмы 3–6 / квадрат / 4–7–8, 1 мин / 3 круга / 3 мин, пауза, звук по желанию, Wake Lock |
| 5-4-3-2-1 | `grounding.js` | 5 экранов, точки можно отмечать |
| Разобрать тревожную мысль | `thought.js` | КПТ: ситуация → мысль (подсказка ловушки) → чувство и сила → взгляд со стороны → было/стало; при «невыносимо» — стоп и живой человек |
| Контакт с чувствами | `feelings.js` | 3 шага, итог «что вы заметили» |
| Отложить мысли до утра | `envelope.js` | выписать и «запечатать», текст стирается |
| Шум для сна | `noise.js` | ровный/мягкий/глубокий, таймер с плавным затуханием, играет при заблокированном экране |
| Что сказать близким | `words.js` | готовые фразы по адресатам, копировать/отправить |
| Попросить о помощи | `request.js` | конструктор «факт → чувство → важно → просьба» |
| Ловушки мышления | `traps.js` | 12 карточек-перевёртышей и мини-игра |
| Колода опор | `deck.js` | 54 фразы по состояниям, сохранить картинкой |
| Если накрывает воспоминание | `flashback.js` | тихий якорь с сегодняшней датой, без анимаций |
| Экстренная остановка | `stop.js` | 5 крупных шагов, тёмный экран, готовое сообщение близкому |

Тексты — в `js/content/` (`voice.js`, `thinking.js`, `words.js`).

## Проверки

```bash
pip install playwright
python server.py &
python qa/test_site.py      # отчёт — qa/site-report.json
```

24 сценария: отсутствие горизонтальной прокрутки на 320–1440 px, тема, переходы к записи, вкладки этапов и передача темы в письмо, письмо и ссылки SMS/Telegram, подсказка помощи при кризисных словах, фильтр практик, каждая из 12 практик, шторки, мобильное меню и панель, отсутствие записей в localStorage/cookies и внешних запросов. Скриншоты не делаются. Путь к Chromium задаётся `CHROME_PATH`.
